Settings

API Providers

Add multiple keys per provider — they rotate automatically and rate-limited keys are skipped. Failover: built-ins by latency → custom providers → the Offline Brain as last resort.

Note: shared keys are stored unencrypted on this device (any local user can read them).

Bring Any Provider

Paste any API key — Phantom detects the provider, endpoint and model list on its own. Recognizes xAI (Grok), Anthropic, DeepSeek, SiliconFlow, self-hosted vLLM/Ollama and any OpenAI-compatible API. Known keys (Groq, OpenRouter…) auto-fill their built-in slot.

👻 Offline Brain WebGPU

Runs an LLM entirely on this device — no API key, no internet, free forever. Nothing downloads automatically — press Enable, pick a model, then Load now whenever you're ready. If your device runs out of memory, only the brain pauses; Phantom itself never crashes.
